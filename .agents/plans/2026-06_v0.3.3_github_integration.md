# GitHub Integration for Vault Document Management (v0.3.3)

## Goal Description
Integrate GitHub directly into the Incurator backend and Obsidian plugin to allow seamless vault document management via git commits and remote repository syncing. This includes handling GitHub authentication (Login/Logout workflows), displaying git status (uncommitted changes, branches, ahead/behind), and providing a streamlined UI in the Dashboard to commit and push knowledge graphs without leaving Obsidian.

## Design Decisions (Aligned via /grill-me)

1. **Authentication Mechanism**: We will rely on the GitHub CLI (`gh`). The plugin will run `gh auth status` to check login state, and `gh auth login` to prompt the user. This avoids building a custom OAuth flow.
2. **UI Placement**: The GitHub Auth status and management will be placed in the **Obsidian Plugin Settings** page, directly below the "AI Provider" section. It will not be an Overview card.
3. **Commit/Sync Workflow**: There will be **no** manual "Commit" or "Sync" UI buttons. Instead, Git operations will be exposed to the **Sidechat (Antigravity LLM)** as tools. The user can type "Commit my changes" or "What's the status of my remote repository?" and the AI will execute git commands and summarize the history.
4. **.gitignore Scope**: By default, the `.curator/` directory (SQLite DB, search indices) will be ignored to prevent large binary conflicts. Only markdown files and standard configuration will be tracked.

## Proposed Changes

### Backend & AI Capabilities (Python)
- `backend/src/curator/git_manager.py`: Create a wrapper module to safely execute standard `git` commands (status, log, push, pull, commit).
- **LLM Tool Registration**: Expose new tools to the Antigravity chat system so the AI can answer git-related queries (e.g., `get_git_status`, `get_git_history`, `execute_git_commit`).

### Plugin UI (TypeScript)
- `plugin/src/settings.ts`: Add a "GitHub Integration" section right below "AI Provider". Add logic to check `gh auth status` and display the current logged-in GitHub account, with a button to launch `gh auth login` in the terminal if unauthenticated.
- `plugin/src/auth/cliAuth.ts`: Expand existing CLI auth resolver to support `github` via the `gh` command.
