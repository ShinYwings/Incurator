# Source-Pair Analyst Proposal: Pack Assembly Cannot Upgrade Evidence

Date: 2026-06-11 | Agent Persona: source_pair_analyst

## 1. Core Logic & Implementation

ContextService receives Plan-A retrieval results and Program-2 trusted evidence.
Pack assembly may summarize, omit, or progressively disclose items, but it cannot
broaden support, upgrade uncertainty, replace source text, or detach locators.
Verification must reach the same minimal support used during selection.

## 2. Pros & Cons

Pros: prevents polished context packs from hiding compiler/retrieval defects.
Cons: unsupported or stale evidence may yield visibly incomplete packs instead
of convenient but unverifiable answers.
