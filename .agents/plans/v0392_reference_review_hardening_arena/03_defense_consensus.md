# Critique on Red-Team Failure Scenarios
Date: 2026-08-01 | Agent Persona: System Synthesizer

## 1. Vulnerabilities & Flaws

The proposal is accepted with the red-team restrictions. Two over-broad
interpretations are rejected:

- Do not suppress every BM25-resolved equation reference. Fail-closed behavior
  applies only to single-number equation pointers that entered the exact-label
  adjacent expansion path.
- Do not infer turn focus from PDF visibility or filename. Use the existing
  active-tab and explicit-context document identity.

Schema Guardian verdict: no database or persisted-state contract changes.
Source-Pair Analyst verdict: no DAG, retrieval, or provider permission changes;
the correction is limited to prompt-context selection before provider launch.

## 2. Suggested Alternatives

Consensus implementation:

1. Write the false-positive and mixed-focus tests first.
2. Preserve exact matches immediately; after queue exhaustion, mark only the
   still-loose expanded equation pointers unresolved.
3. Add a pure, identity-based PDF-focus eligibility predicate and call the
   latest-user resolver only when it passes.
4. Verify the successful page-6 fixture, request cap/order, explicit PDF
   context, selected/cropped paths, and full plugin suite.
5. Update English/Korean docs and system behavior spec before runtime code.

This is a merge-blocking correction inside the existing v0.39.2 PR, not a new
release or capability.
