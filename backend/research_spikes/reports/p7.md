# Plan E P7 Report — Untouched Holdout, Red Team, And Decision Synthesis

Date: 2026-06-12
Status: Completed; awaiting PM review of the final decision package (P8)

## Scope

P7 consumed the four research-spike holdout items exactly once under the
frozen Wave A-D configurations: `RUQ05` (retrieval units), `GQ07` (graph
stress), `HQ01` (serving stress), and `FR05` (formula recovery). No
configuration, threshold, budget, or corpus was changed before or after the
run; corpus hashes were verified identical before and after measurement. The
Failure Atlas qrels holdout (`Q06`) was **not** consumed — the qrels reserve it
for a D2-approved evaluation procedure, and this report records that
reservation explicitly.

All four holdout probes were authored at P0 as deliberately blind items
(`hidden ...` query texts, a hidden proven-loss page). They therefore measure
the honesty and structural invariants of the frozen candidates — explicit
failure reporting, no fabrication, bounded budgets, resolvable provenance —
rather than rewarding tuned semantic matches. `GQ07` is the exception: graph
traversal consumes seeds, not query text, so it yields a real recall signal.

## Holdout Results

### RUQ05 — Retrieval Units (Wave A frozen variants/modes)

| Variant | Mode | Recall@1 | Recall@5 | Top-1 citation correctness | Hard-negative outranks | Provenance resolution |
|---|---|---:|---:|---:|---:|---:|
| raw/heading/context | lex | 0.00 | 0.00 | 0.00 | 0 | 1.00 |
| raw/heading | vec, hybrid | 0.00 | 1.00 | 0.00 | 2 | 1.00 |
| context | vec, hybrid | 0.00 | 1.00 | 0.00 | 2 | 1.00 |

The probe text shares no vocabulary with any document. Lexical retrieval
honestly returned nothing. Vector/hybrid returned collision-noise rankings in
which both hard negatives outranked the expected record and the expected
record ranked last. **This is the central diagnostics finding: aggregate
Recall@5 alone reports `1.00` (apparent success) on a 5-document corpus, while
top-1 citation correctness (`0.00`) and hard-negative outranks (`2`) expose
the failure.** The fine-grained diagnostics contract did exactly what it was
adopted to do, on data it had never seen.

### GQ07 — Graph Stress (Wave B frozen mechanisms)

Seeds `[N06]`, expected path `N06 → N07 → N08`.

| Mechanism | Recall | Cost | Note |
|---|---:|---:|---|
| Current depth-2 memory walk | 1.00 | 4 paths | reaches N08 through the 0.25 edge |
| Unfiltered weighted PPR (top 4) | 1.00 | 660 edge updates | again surfaces noisy-bridge node N14 |
| Filtered bounded expansion (min 0.5, budget 8) | 0.50 | 4 traversed edges | misses N08: true edge below threshold |

The holdout exposed the confidence-filter trade-off the measured partitions
could not: the true `N07 → N08` ecology-link edge carries confidence `0.25`,
below the frozen `0.5` filter, so filtered expansion honestly missed it while
staying within budget and keeping every addition explainable
(seed/path/edge-kinds/`SPAN-` provenance all present). Unfiltered PPR reached
`N08` but ranked the noisy-bridge distractor `N14` in its top 4 — repeating
the Wave B noise leak at 165x the traversal cost. Neither mechanism dominates:
the filter threshold is a correctness/noise dial that cannot be set until
Program 2 makes relation confidence discriminative.

### HQ01 — Serving Stress (Wave C frozen classifier)

The blind probe (`hidden holdout routing probe`) carries no global or
iterative signal; the frozen regex classifier routed it `local`, matching the
oracle, at token cost `1` versus `6` for always-most-complex. One trivial
probe; no posture upgrade.

### FR05 — Formula Recovery (Wave D frozen policies)

A proven-loss page with no recovery candidate. All policies scored formula
recall `0.00`; selective recovery **fabricated nothing** (no recovered
formulas, no distillation-added formulas), the loss remained explicit, and
selective cost was `0` versus `10` for whole-corpus processing of the page.
The no-fabrication invariant held under total loss.

## Rejected Defaults (Consolidated)

- Aggregate-only retrieval reporting and model-judge-only release gates.
- Generated context treated as source evidence.
- Unfiltered graph-only PPR over the current graph.
- Loading every community report for every global query.
- Graph additions without seed/path/provenance/budget explanations.
- A silent fixed character cutoff for served context.
- Unbounded or snapshot-mixing iterative retrieval.
- Whole-corpus heavy visual recovery as the default formula pipeline.
- Distillation that silently drops formulas present in authoritative extraction.
- A fixed confidence threshold treated as a calibrated noise filter (GQ07).

## Revisit Triggers

- **kg-guided-expansion / passage-entity-ppr / denoised-hierarchy:** re-run
  after Program 2 delivers discriminative relation confidence and graph-quality
  gates; GQ07 shows the 0.5 threshold both blocks noise and loses truth.
- **query-relevant-global / progressive-context-disclosure:** validate against
  realistic global/disclosure holdout cases when Program 3 builds its own
  evaluation set; the P7 confirmation is contract-level, not mechanism-level.
- **context-enriched-chunks:** realistic fixtures plus measured source-edit
  invalidation and cache cost.
- **selective-formula-recovery:** a real VLM/provider measurement of recovery
  confidence calibration on proven-loss pages.
- **Failure Atlas holdout (Q06):** remains frozen for the D2-approved
  evaluation procedure.

## Limitations

- All holdout items are synthetic, blind-by-construction probes; they validate
  honesty and invariants, not realistic-scale quality.
- The holdout contains no global-family, sufficiency, iterative, or disclosure
  case, so those candidates' P7 evidence is audit-based; coverage limitations
  are recorded inline above.
- The deterministic token-hash embedder is a control, not evidence about the
  production embedder; the RUQ05 noise rankings quantify diagnostic honesty,
  not production retrieval quality.
