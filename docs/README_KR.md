# 🧠 Incurator: 멀티 에이전트 워크스페이스를 위한 지식 컴파일러 & 연구 어시스턴트

[English](README.md) | **한국어**

**"PDF와 노트를 로컬 AI 컴파일러에 맡기세요. 내 지식에 기반해 질문하고, Cursor처럼 노트를 편집하며, MCP로 코딩 IDE에 볼트 지식을 연동하세요."**

Incurator는 연구자, 엔지니어, 지식 노동자를 위해 설계된 지능형 지식 컴파일 엔진이자 옵시디언(Obsidian) AI 어시스턴트입니다. 방대한 원본 자료(PDF, 마크다운 노트, 논문 등)를 구조화된 **방향성 비순환 그래프(DAG)**로 변환하여, 내 지식 기반으로 탐색, 질의, 편집, 합성을 수행할 수 있도록 지원합니다. 제공되는 모든 발견 사항은 근거가 되는 source span을 정확히 인용하며, 인용할 수 없는 발견 사항은 아예 생성되지 않습니다 — 답변이 모델의 기억이 아니라 사용자 본인의 자료까지 추적됩니다.

> 시스템의 설계 철학과 기존 LLM Wiki들의 한계를 극복한 아키텍처 배경은 [프로젝트 철학](philosophy/ABOUT_KR.md) 문서를 참조하세요.

## 🚀 사용자가 경험하는 핵심 워크플로우

```
  [볼트 원본 자료] (03_Notes/, 04_Resources/, Zotero PDF)
       │
       ▼ (wiki add / wiki build)
┌──────────────────────────────────────────────────────────────┐
│ 🏛️ The Curator (.curator/ 및 state.sqlite)                   │
│   L1 맥락(Context) → L2 원자(Atoms) → L3 개념 → L4 합성     │
│   (로컬 SLM / 백그라운드 워커가 저비용으로 지식 컴파일)      │
└──────────────────────────────┬───────────────────────────────┘
                               │
                               ▼ (curate.yml 기반의 동적 큐레이션 렌즈)
┌──────────────────────────────────────────────────────────────┐
│ 🎨 The Artist (옵시디언 사이드바 & Universal MCP 서버)       │
│   • 열린 PDF 분할 뷰 연동 & 소스 상태 배지                   │
│   • 텍스트 드래그 인라인 팝오버 질문 ("Ask Gemini" 스타일)   │
│   • Cursor 스타일의 인터랙티브 인라인 Diff 노트 편집         │
│   • 다중 출처 하이브리드 검색 & 정확한 출처 인용 답변         │
│   • 외부 코딩 IDE(Cursor, VSCode)를 위한 실시간 컨텍스트 제공 │
└──────────────────────────────┬───────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            ▼ (Diff 리뷰를 통한 선별 수정)        ▼ (wiki query "save" / 명시적 승격)
    [03_Notes/] (업데이트된 내 노트)       [02_Wiki/] (영구 위키 지식)
```

1. **자료 등록 (`wiki add`)**: 내 생각과 일상 메모(`03_Notes/`)나 논문/PDF 자료(`04_Resources/`)를 등록하면 LLM 호출 없이 문서 구조에 기반한 L1 맥락(Context)을 즉시 생성합니다.
2. **지식 컴파일 (`wiki build`)**: 가벼운 백그라운드 모델(로컬 Ollama SLM 등)이 사실 단위의 L2 원자(Atoms)를 추출하고, 다중 문헌을 아우르는 L3 개념(Concepts)으로 클러스터링합니다.
3. **액티브 리딩 & 팝오버 질문 (Obsidian Studio)**: PDF를 분할 뷰로 열고, 텍스트나 수식을 드래그하여 즉각 팝오버로 질문하거나 사이드바에서 정확한 출처 인용과 함께 대화합니다.
4. **인터랙티브 노트 편집 (Diff Viewer)**: AI가 제안한 노트 수정안을 채팅창에서 복붙할 필요 없이, CodeMirror 6 기반의 인라인 Diff 뷰어에서 라인별 변경사항(`+` / `-`)을 확인하고 선별 수락(Accept) / 거절(Reject)하여 `03_Notes/`의 노트를 안전하게 업데이트합니다.
5. **프로젝트 맞춤 큐레이션 (`curate.yml`)**: 워크스페이스별 프로젝트 목적과 도메인 규칙을 선언하여, 에이전트가 오염되지 않은 고신뢰 근거만을 선별 검색하도록 유도합니다.
6. **Universal MCP 연동**: Cursor나 Claude Desktop에서 코딩할 때 내 옵시디언 볼트에 담긴 연구 자료와 설계 문서를 실시간 참조합니다.

## 🌟 Incurator만의 6대 핵심 슈퍼파워

### 1. Obsidian Studio: 액티브 리딩 & Cursor 스타일 Diff 편집
- **인라인 팝오버 ("Ask Gemini" 스타일)**: 노트나 PDF에서 텍스트 또는 수식을 드래그하면 플로팅 버튼이 나타나며, 내 볼트 지식에 기반한 즉각적인 질의응답을 수행합니다. LaTeX 수식 렌더링을 완벽히 지원합니다.
- **인터랙티브 Diff Viewer**: AI의 수정 제안이 노트를 함부로 덮어쓰지 않습니다. 에디터 내에 Git 스타일의 인라인 Diff 화면을 띄워 변경된 블록을 시각적으로 검토하고 청크 단위로 선별 적용할 수 있습니다.
- **PDF 분할 뷰 연동**: PDF를 드래그 앤 드롭으로 분할 뷰에 배치하고, 인덱싱 상태 배지를 실시간 확인하며, 인용 링크 클릭 시 해당 페이지로 즉시 이동합니다.

### 2. 계층형 지식 DAG vs 평면 위키의 한계 극복
기존 오픈소스 LLM Wiki들은 수백 개의 평면 마크다운을 쏟아내어 컨텍스트 윈도우가 폭발하고 환각이 누적됩니다. Incurator는 **4단계 계층형 방향성 비순환 그래프(DAG)**로 지식을 컴파일합니다:
- **L1 Contexts**: 원본 문서 구조 및 페이지 위치 파악 (LLM 토큰 소모 0).
- **L2 Atoms**: 원본에 철저히 기반한 분해 불가능한 사실 단위.
- **L3 Concepts**: 다중 문헌을 횡단하는 주제별 개념 클러스터 및 리포트.
- **L4 Synthesis**: 말뭉치 전체를 아우르는 공유 상위 지식 노드.
- **심층 모순(Contradiction) 탐지**: `wiki lint --deep` 명령어로 볼트 내 서로 다른 논문 간의 사실 충돌을 사전에 탐지합니다.

### 3. Zotero 무손실 연동 & 애플펜슬 해시 드리프트 방어
- **Reference Mode**: Zotero 라이브러리와 외부 PDF를 볼트 내부로 중복 복사하지 않고 원래 위치 그대로 안전하게 참조합니다.
- **해시 드리프트 방어**: iPad에서 애플펜슬로 PDF에 필기하거나 하이라이트하여 파일 해시(SHA256)가 변경되더라도, 논리적 출처 ID를 추적하여 기존 L1~L3 지식 그래프와 인용 링크를 깨뜨리지 않고 자동으로 복원(Rebind)합니다.

### 4. Universal MCP 서버: 코딩 IDE를 위한 외부 두뇌
Incurator는 **48개 이상의 도구**를 제공하는 고성능 MCP(Model Context Protocol) 서버를 내장하고 있습니다:
- **Cursor, VSCode, Antigravity IDE, Claude Desktop** 등과 원클릭 연동.
- IDE에서 코드를 작성할 때 `curator_fetch_context` 도구 등을 호출하여, 내 옵시디언 볼트에 저장된 아키텍처 문서, 논문, 연구 노트를 코딩 에이전트의 사전 지식으로 직접 활용할 수 있습니다.

### 5. AI FinOps: 컴파일 비용 0원 + 자유로운 모델 선택
- **로컬 백그라운드 컴파일**: 반복적인 데이터 파싱과 지식 구조화(`L1 → L2 → L3`)는 로컬 SLM(Ollama)이나 경량 워커가 0원에 가깝게 처리합니다.
- **상용 추론 모델 활용**: 심층 대화와 복잡한 지식 합성에만 상용 고성능 모델(Claude, OpenAI, Gemini 등)을 선별 사용하여 전체 토큰 비용을 90% 이상 절감합니다.

### 6. 매끄러운 다중 기기 동기화 (Syncthing & iCloud)
- SQLite WAL 체크포인팅, 결정론적 상대 경로, 자동화된 `.stignore` 규칙을 적용하여 Mac, iPad, Linux 간 충돌 없는 안전한 동기화를 보장합니다.

## 🏛️ 시스템 아키텍처: Curator & Artist

Incurator는 지식 관리의 역할을 두 주체로 엄격히 분리합니다.

### ⚙️ The Curator (볼트의 관리자)
`.curator/`에 상주하는 백그라운드 엔진입니다. 고도의 창의적 추론 대신 **지식의 구조화, 컴파일, 인덱싱 및 무결성 감사**를 전담합니다.
- `state.sqlite`가 단일 진실 공급원이며, `.curator/Collections/`의 마크다운 파일들은 언제든 삭제하고 다시 빌드할 수 있는 점검용 프로젝션입니다.

### 🎨 The Artist (워크스페이스의 창작자: 인간 + 에이전트)
옵시디언 사이드바나 MCP를 통해 사용자와 협업하는 고성능 추론 주체입니다.
- **동적 큐레이션 렌즈**: 고정된 하위 복사본을 만드는 대신, `curate.yml` 명세를 쿼리 시점에 라이브 DAG 위에 렌즈 형태로 동적 적용합니다.
- **무상태(Sessionless) 질의**: 질문을 던지는 행위 자체는 DAG를 오염시키지 않습니다. 모든 질의는 출처 인용 및 추적 정보가 포함된 답변을 반환합니다.
- **명시적 승격(Promotion)**: 가치 있는 결과물은 인간의 명시적 승인을 거쳐야만 `02_Wiki/`의 영구 지식으로 보존됩니다.

## 🛠️ 시작하기

### 📋 사전 요구 사항
- **Python 3.10+**
- **옵시디언 (Obsidian)** (인터랙티브 UI 권장)
- **로컬 / 클라우드 LLM**: 로컬 모델(Ollama) 또는 클라우드 API 키(Claude, OpenAI, Gemini 등).

### 🚀 빠른 시작 (Quick Start)
1. **설치 및 모노레포 빌드**:
   ```bash
   ./setup.sh
   ```
   *파이썬 의존성 설치, 옵시디언 플러그인 빌드 및 로컬 도구 설정을 한 번에 진행합니다.*

2. **볼트 초기화**:
   ```bash
   wiki init /path/to/your/obsidian-vault
   ```
   *간단한 인터뷰를 통해 볼트의 Curator 페르소나를 설정합니다.*

3. **자료 등록**:
   ```bash
   wiki add /path/to/document.pdf
   ```
   *LLM 비용 없이 L1 문서 구조를 즉각 생성합니다.*

4. **지식 레이어 컴파일**:
   ```bash
   wiki build
   ```
   *백그라운드에서 L2 원자 및 L3 개념을 추출·클러스터링합니다.*

5. **질의 및 지식 탐색**:
   ```bash
   wiki query "등록된 논문들에서 발견된 핵심 결과는 무엇인가요?"
   ```
   *또는 옵시디언을 열어 사이드바 및 인라인 팝오버로 노트와 PDF를 실시간 탐색합니다.*
