이 폴더는 가설 검증 코드(Code-based Verification)를 실행한 뒤 도출되는 **각종 결과물(Artifacts)**을 저장하는 공간입니다.

  

- 저장 대상: 검증을 통해 얻은 텐서 덤프(JSON), 시각화된 매니폴드 혹은 오차 그래프(PNG/PDF), 수치적 최적화 로그 등.

- 원칙: 수학적 가설을 검증할 때 증거 자료(Evidence)로 쓰이는 모든 생성물은 이곳에 보관하며, `related_works.md`나 `methodology.md` 작성 시 이 자료들을 레퍼런스로 사용합니다.
