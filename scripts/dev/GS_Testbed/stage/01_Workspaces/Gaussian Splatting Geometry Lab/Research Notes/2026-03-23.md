## 📌 Daily Executive Summary (요약)

오늘 도출된 치명적 병목 지적 및 기하학적 해결책 방안을 **한눈에 보기 위해 요약**한 섹션입니다.

  

1. **Unscented Transform (UT) 폐기 및 UOT 대안**: $Rank$ 퇴화 방어 목적의 UT는 연산량/가상 커널 병목으로 기각. 대신 최적 수송(Unbalanced Optimal Transport)으로 코스트 우회 검토.

2. **SAM2 트래킹 기각, GS 자체가 메모리 뱅크**: SAM2의 2D 픽셀 기반 트래킹은 3D 공간 기하 인지 불가로 기각. 메모리 뱅크 개념은 차용하되, 별도 모듈이 아니라 **3D 가우시안들 자체가 곧 씬의 기하학적 상태를 누적 저장하는 메모리 뱅크** 역할을 한다.

3. **2DGS 역투영(Lifting)과 MVG의 수학적 동치성(Equivalence) 발견**: 3D 가우시안의 투영 공식($\Sigma_{2D} = J \mathbf{W} \Sigma_{3D} \mathbf{W}^T J^T$)이 사영 기하학(MVG)의 **'쌍대 이차곡면(Dual Quadric) 투영'**과 완전히 동일함을 인지. 단일 View의 $Null$ $Space$를 피해, 다중 뷰(Fundamental Matrix) 대수적 삼각측량(Algebraic Triangulation)으로 $\Sigma_{3D}$를 복원(Lifting)하는 돌파구 확보.

4. **2DGS의 특이점(Singularity) 방어 꼼수 발견**: $\Sigma_{3D}$(디스크)를 측면(Edge-on)에서 볼 때 $Rank=1$이 되어 폭발($NaN$)하는 것을 막기 위해, 코딩 단에서 Low-Pass Filter(대각 성분 $+0.3f$)를 슬쩍 더해 2차원 표면 가정을 스스로 파괴하는 논리적 비약(Logical Leap) 맹점 발견.

5. **TSP/3DGS ADC/UOT Birth-Death의 통합적 UOT 관점**: TSP의 split/merge/remove/switch, 3DGS ADC의 Split/Clone/Prune, UOT의 질량 생성/소멸은 하이레벨에서 보면 모두 **'질량이 보존되지 않는 분포 변환' = UOT 문제**로 볼 수 있다. (주의: 수학적 등가 주장이 아닌 하이레벨 프레이밍)

6. **궁극적 연구 비전 정립**: 프레임별 씬 변화 자체를 UOT 문제로 보고, 이를 확률 프로세스(Stochastic Process)로 치환해 풀며, 다음 씬 예측의 Prior를 GS(메모리 뱅크)로부터 얻는다. 기술적 서브프로블러: (1) 2D 이미지 → GMM 변환, (2) Two-view에서 대응 Gaussian 추출 → 3D Lifting, (3) Lifted GS = GS Prior.

7. **핵심 기술적 설계 결정**: TSP hard boundary를 soft constraint + auto-diff로 변환(2-Wasserstein 검토 중). 프레임 간 서로 다른 유클리드 공간 문제는 CF-GS`[44]`처럼 첫 프레임=월드 공간으로 처리(metric depth X). 프레임 간 정합은 RegGS`[27]`를 레퍼런스로 삼음.

## 🗣 오늘의 연구 디스커션 (Daily Discussion Log)

*Meta 대화 제외: 순수 연구/방법론 토의 내용 기록*

  

- **Unscented Transform (UT) 도입 보류 판정**:

- $Rank$ 퇴화 극복을 위해 $Positive$ $Semi-definite$ 보존 확률론적 삼각측량 프라이어로 제안되었던 **UT**를 구조적 복잡성과 실시간 SLAM 연산의 컴퓨팅 병목 가능성(가상 커널 프로파일링 예상)을 이유로 보류(Drop)함.

- **대안 모색 방향**: 기존 $Jacobian$ 1차 선형 근사(`Taylor Expansion`)의 한계를 피하면서도 UT만큼 무겁지 않은, 파라미터 변환 역전파(Backpropagation) 최적화 우회 로직이나 3D 공간 상의 **최적 수송(UOT)**을 보다 가벼운 코스트 함수로 구현할 기술적 타협점(Engineering Compromise) 탐색이 시급함.

- **SAM2 트래킹 기하학적 기각 및 Memory Bank 차용**:

- SAM2는 2D 픽셀 기반 메커니즘이므로 깊이($Z$)나 카메라 에피폴라 기하(Epipolar Geometry)와 같은 본질적인 공간 정보(Spatial Information)를 전혀 인지하지 못한다.

- 따라서 3DGS 궤적 최적화에 SAM2의 트래킹 수식을 그대로 가져오는 것은 수학적 비약(오류)이므로 **폐기**한다.

- 단, 과거 프레임의 정보들을 누적하여 활용하는 **메모리 뱅크(Memory Bank)** 개념은 차용. 다만 별도 모듈이 아니라, **3D 가우시안들 자체가 씬의 기하학적 상태(Prior)를 누적 저장하는 메모리 뱅크** 역할을 한다.

- **2DGS Lifting과 MVG (Dual Conic) 투영의 수학적 동치성(Equivalence) 발견**:

- 사용자 제안에 따라 `paper/` 폴더 내의 Multiple View Geometry (Hartley & Zisserman) 및 Auto-calibration (Steiner Conic 등) 문헌 검토.

- **핵심 통찰**: 2D 가우시안의 공분산 행렬 $\Sigma_{2D}$는 사영 기하학에서 **쌍대 원뿔곡선(Dual Conic) $\mathbf{C}^*$**과 완벽히 동일한 수학적 형태를 지닌다.

- 3D 가우시안 $\Sigma_{3D}$ ($Rank=2$ Disk)의 투영 공식 $\Sigma_{2D} = J \mathbf{W} \Sigma_{3D} \mathbf{W}^T J^T$ 는 MVG에서의 3D 쌍대 이차곡면(Dual Quadric) $\mathbf{Q}^*$의 투영 공식 **$\mathbf{C}^* = \mathbf{P} \mathbf{Q}^* \mathbf{P}^T$** 과 완전히 동치(Isomorphic)이다!

- 따라서 단일 이미지에서의 Lifting Inverse Problem(역문제)은 해결 불가능하지만, 2개 카메라 쌍에서 얻은 2D 쌍대 원뿔곡선(Dual Conic)들 간의 에피폴라 제약(Fundamental Matrix $\mathbf{F}$)을 부여하면, 3D Quadric의 파라미터(Disk의 Normal과 Depth)를 대수적 복원(Algebraic Triangulation) 문제로 치환 가능함.

- **2DGS의 치명적 기하학적 비약(Logical Leap): 특이점 꼼수(LPF)**:

- 2DGS는 Jacobian 1차 근사 없이 피보나치 투영이나 Bounding Box 계산 등에서 쌍대 이차곡면(Dual Quadric)의 호모그래피 투영식을 닫힌 형태(Closed-form)로 정확히 풀어낸다.

- 그러나 진정으로 치명적인 논리적 비약은 **"Edge-on(측면) View에서의 Rank 붕괴(Singularity)를 막기 위한 인위적인 Low-Pass Filter(LPF) 주입"**에 있다.

- 원반(Disk)을 완벽한 측면에서 보게 되면 사영 기하학적으로 2D 공분산 $\Sigma_{2D}$는 선분 형태가 되어 역행렬 식 계산 시 행렬식이 0($NaN$)이 되어 폭발한다.

- 이를 막기 위해 2DGS 구현체 내부에서 이 공분산 행렬의 대각 성분 또는 고유값에 강제로 `0.3f` 등의 LPF 상수를 더한다.

- **기하학적 모순**: "우리는 볼륨 렌더링을 버리고 완벽한 2차원 표면(Rank=2)을 렌더링한다"고 수학적으로 정의해 놓고서, 정작 렌더러가 터지는 걸 막기 위해 코딩 단에서 원반을 다시 위아래로 살짝 부풀려 '얇은 3D 타원체(Rank=3)'처럼 취급해버리는 자가당착적 모순을 저지른 셈이다.

- **TSP/3DGS ADC/UOT의 통합적 UOT 관점 논의**:

- TSP의 split/merge/remove/switch, 3DGS ADC의 Split/Clone/Prune, UOT의 Birth-Death Process는 하이레벨에서 보면 모두 **"질량이 보존되지 않는 분포 변환"**이라는 공통 구조를 갖는다. 이는 UOT 문제의 인스턴스로 바라볼 수 있다.

- **비판적 주의**: 이것은 수학적 등가(Isomorphism) 주장이 **아니라** 하이레벨 프레이밍임. 리뷰어에게 "relabeling 아니냐?"라고 공격받지 않으려면, UOT로 재해석함으로써 기존 heuristic이 할 수 없는 **기하학적 제약 인코딩 + 글로벌 최적 질량 재배치**를 제공한다는 차별점이 필수적이다.

- **궁극적 연구 비전 정립 (파이프라인 전체상)**:

- **문제 정의**: 프레임별 씬 변화 자체를 **UOT 문제**로 본다. 이를 **확률 프로세스(Stochastic Process)**로 치환해 푼다.

- **Prior 획득**: 다음 씬의 정보를 예측하기 위해 **Gaussian Splatting 자체가 메모리 뱅크(Prior)** 역할을 한다.

- **기술적 서브프로블러 3가지**:

1. **2D 이미지 → GMM 변환**: TSP 기반 Superpixel을 가우시안 상태(State)로 변환

2. **Two-view에서 대응 Gaussian 추출 → 3D Lifting**: MVG Dual Conic/Quadric 대수적 삼각측량으로 $\Sigma_{3D}$ 복원

3. **Lifted GS = GS Prior**: Lifting된 3D 가우시안은 GS 표현과 동일하며, 이것이 다음 프레임의 Prior로 작동

- **핵심 기술적 설계 결정들 (기술적 서브프로블러 구체화)**:

- **(A) TSP Hard Constraint → Soft Constraint 변환**: TSP는 각 가우시안 영역이 hard boundary로 되어 있어 미분 불가능. 이를 soft constraint로 바꾸고 auto-diff 구조로 변환해야 함. **2-Wasserstein Distance**를 사용하여 가우시안 간 soft 대응을 정의하는 방안 검토 중.

- **(B) Two-view Lifting (3D Initialization) 고도화 (브레인스토밍)**:

- 단순 행렬 대수(Algebraic solver)만으로는 노이즈에 취약하고 3D Point 복원 효율이 떨어짐. 따라서 후속 처리로 **Bundle Adjustment (BA)**나 **Gaussian ICP (g-ICP)** 병용이 필수적.

- **Keyframe 기반 매칭 결정**: 비디오의 모든 매 프레임을 잡으면 Parallax 부족으로 붕괴함. **On-the-fly NVS** 기법을 채택. (카메라 Translation/Rotation 변화량이나 신규 관측 영역을 추적하여, 충분한 베이스라인이 생겼을 때만 Keyframe으로 뽑아 Lifting).

- **Tangent Plane(2DGS) Lifting의 재검토 (🚨 Critical Refinement)**:

- **호모그래피의 함정**: 단순히 $\Sigma_1 = H \Sigma_2 H^T$ 식으로 Lifting하는 것은 해당 가우시안이 '불투명한 단일 평면'일 때만 유효함. 2DGS는 Alpha-compositing 기반의 Semi-transparent accumulation이므로, 이 등식은 물리적으로 불완전함.

- **해결책**: Homography는 오직 **Geometric Initialization (Prior)** 수준에서만 사용하고, 최종 3D 파라미터 결정권은 **Alpha-aware Splatting Loss**로 넘겨야 함.

- **Triangulation 분리**: 3D 위치($\mu_{3D}$)는 $L_\infty$ Norm[39]으로 아웃라이어를 제거하며 잡고, Disk의 Orientation($n$)은 Angular Error[13]를 최소화하는 방향으로 초기화하여, 렌더링 최적화가 Local Minimum에 빠지지 않도록 유도.

- **(C) 서로 다른 유클리드 공간 문제 해결**: Frame 간 two-view에서 lifting한 3D 가우시안들은 각각 로컬 카메라 좌표계에 존재하여 서로 다른 유클리드 공간에 있음. **CF-GS`[44]` 접근**: 첫 번째 프레임의 로컬 3D 공간을 **월드 공간처럼 사용** (metric depth 추론 없이).

- **(D) 프레임 간 정합(Registration)**: 이전 프레임 공간과 현재 프레임 공간의 GS를 정합하기 위해 **RegGS`[27]` 방식을 레퍼런스**로 삼음. Bundle Adjustment와 유사한 역할.

- **(E) 리뷰어 반론 예상 (🚨 Devil's Advocate) 및 우리의 대응 전략**:

- **[공격 1] 2-Wasserstein 관련**: GMM 전체의 $W_2$는 closed-form이 없는데 어떻게 계산/근사할 것인가? 오차 바운드는?

- **우리의 대응 방안**: 전체 GMM의 연속 $W_2$를 직접 풀지 않고, 각 GS 컴포넌트를 "질량 $w_i$를 가진 점"으로 취급하는 **컴포넌트 레벨 이산(Discrete) $W_2$**로 근사하여 해결함. 확장된 특징 공간 $(\mu, \Sigma, c)$에서 개별 쌍의 Bures metric + 색상 거리를 ground cost로 사용하면 닫힌 해로 정확히 풀 수 있음.

- **보조 검증 수단**: $W_2$ 코스트(컴포넌트 기하/색상 정합)와 **SSIM**(전체 이미지 렌더링 결과의 구조적 유사도)을 병용. 논문에서는 "SSIM 이미지 재구성 에러가 W2 이산 근사의 최적화 품질을 간접적으로 보장한다"는 논리로 방어 예정 (단, gradient 충돌 방지를 위한 $\lambda$ 스케줄링 검토).

- **[공격 2] CF-GS 스케일 모호성 관련**: 첫 프레임을 월드로 가정하면 발생하는 **scale ambiguity**(Metric depth 부재) 문제는 어떻게 처리할 것인가?

- **우리의 대응 방안**: 본 연구의 핵심 목표는 "상대적 스케일에서의 연속적 씬 복원(Scene Reconstruction)"이므로 절대적 Metric recovery는 명확히 Scope 밖(Future work)으로 규정하여 스코프 방어.

- **[공격 3] RegGS 설정 차이 관련**: RegGS는 sparse view + unposed 설정인데, 본 연구의 sequential video 환경과 어떻게 호환/차별화되는가?

- **우리의 대응 방안**: Sequential video는 연속 프레임 간 부드러운 카메라 궤적 변화와 아주 작은 baseline이라는 **더 강한 기하학적 제약**을 내포함. 이는 Registration에서 훨씬 유리한 조건이므로, RegGS의 방법론을 차용하되 sequential 특성을 활용한 높은 안정성을 본 논문의 강점으로 어필.

- **[공격 4] 2D Optical Flow(SEA RAFT) 사용의 모순**: SAM2의 2D 픽셀 트래킹이 3D 공간 기하를 인지하지 못한다고 기각(Reject)했으면서, 왜 TSP의 초기 궤적 추적에는 똑같이 2D 메커니즘인 SEA RAFT(Optical Flow)를 사용하는가?

- **우리의 대응 방안**: SEA RAFT는 오직 **2D 관측(Observation) 간의 초기 Correspondence(픽셀 매칭)**를 얻기 위한 Pre-processing 단계일 뿐, 이를 3D 궤적 제약으로 직결하지 않음. 실제 기하학적 3D 연속성은 TSP 단계 이후의 **Two-view Lifting (Dual Conic / Epipolar 제약)** 단계에서 확보됨. 즉, 2D Flow 트래킹은 '관측 에러가 포함된 초기값'이며, 에피폴라 기하와 GS Memory Bank Prior (UOT)를 거치면서 3D 공간 상에서 교정(Correction)된다고 방어.

- **[공격 5] Scene Flow(3D) 모델을 쓰지 않은 이유**: 3D 기하가 중요하다면 차라리 최신 Scene Flow 추정 모델을 앞단에 붙이면 되지 않는가?

- **우리의 대응 방안**: 우리의 철학은 "무거운 트래킹 모델에 렌더링 품질을 종속시키지 않는다"임. Optical flow는 단순한 **초기 힌트(Weak hint)**로만 던져지고, 실제 픽셀의 흐름 벡터는 TSP 최적화 과정 및 후속 3D Lifting 파이프라인에서 완전히 재정립(Re-established)됨. GT 위치가 아니라 대략적인 근처(Basin of attraction)로만 보내주는 가벼운 힌트로도 전체 렌더링 퀄리티를 끌어올릴 수 있음을 증명하려는 것임. 만약 Scene Flow를 썼다면 우리의 파이프라인 성능인지 Scene Flow 모델 본연의 성능인지 구분이 모호해짐.
